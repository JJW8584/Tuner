# 옥타브와 시작 최적화 검증

## 옥타브 기준

과학적 음높이 표기법을 사용합니다. A4 = 440 Hz이며 옥타브는 B에서 C로 넘어갈 때 바뀝니다. 일부 DAW의 옥타브 이름과는 기준이 다를 수 있습니다.

| 입력 주파수 | 기대 표시 |
|---|---|
| 41.203445 Hz | E1 |
| 82.406889 Hz | E2 |
| 110 Hz | A2 |
| 220 Hz | A3 |
| 246.941651 Hz | B3 |
| 261.625565 Hz | C4 |
| 277.182631 Hz | C#4 |
| 440 Hz | A4 |
| 493.883301 Hz | B4 |
| 523.251131 Hz | C5 |
| 880 Hz | A5 |
| 1975.533205 Hz | B6 |

`octave_test.dart`는 독립된 16개 주파수 표의 합성 PCM을 검출기부터 음명·옥타브 변환까지 통과시켜 확인합니다. B1→C2, B3→C4, B4→C5 경계와 동일 검출기에서 옥타브가 바뀐 뒤 무음이 되는 경우도 검증했습니다. 계산과 표시 연결에 옥타브 오프셋 오류는 발견하지 못했습니다. 실제 마이크가 기본음보다 배음을 크게 받는 환경의 정확도는 실기 검증이 필요합니다.

## 시작 경로

- Flutter 첫 프레임은 플러그인이나 설정 저장소를 기다리지 않습니다.
- 첫 프레임 이후 설정 읽기와 마이크 시작을 병렬로 수행합니다. 설정 응답이 늦어도 마이크를 시작하며, 응답 후 현재 측정값을 새 기준으로 즉시 재계산합니다. 먼저 변경한 사용자 설정을 덮어쓰지 않습니다.
- 오디오 지원 확인과 분석 isolate 준비도 병렬 수행합니다. 고정 PCM16 지원 여부는 세션 간 캐시합니다. 마이크 권한은 세션마다 확인합니다.
- Android 12+ 시작 테마는 투명 아이콘과 검은 배경을 사용하며 별도 브랜딩 이미지·대기 타이머를 넣지 않습니다. 시스템 시작 창 자체는 OS가 관리하므로 완전히 제거하거나 소요 시간 0을 보장하지 않습니다. 앱 내부의 상단 TUNER 텍스트는 유지합니다.
- iOS 시작 storyboard의 이미지와 흰 배경도 제거했습니다. iOS 빌드는 검증하지 않았습니다.

## 분석 CPU 벤치마크

YIN의 첫 유효 최소값과 오른쪽 보간 표본을 찾으면 계산을 마치고, 프레임 간 작업 배열을 재사용합니다. 기본음 판정 기준과 4096샘플 프레임·44100 Hz 입력은 유지했습니다.

`dart run tool/benchmark_pitch_detector.dart`: 동일 PC / Dart JIT / 100회 준비 실행 / 200회 평균. 아래는 한 번의 전후 실행 결과이며, 모바일 성능이나 앱 시작 시간 측정은 아닙니다.

| 주파수 | 변경 전 µs/프레임 | 변경 후 µs/프레임 |
|---|---:|---:|
| 41.203 Hz | 232.1 | 216.3 |
| 110 Hz | 231.7 | 88.3 |
| 440 Hz | 241.2 | 30.0 |
| 880 Hz | 243.5 | 21.9 |

선택된 신호의 결과 체크섬은 전후 동일했습니다. 저음은 긴 주기까지 확인해야 하므로 개선 폭이 작습니다. 디버그 JIT 실행과 에뮬레이터의 체감 시작 시간은 배포용 AOT 빌드·실제 기기의 성능을 대표하지 않습니다.
